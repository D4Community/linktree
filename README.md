# D4 Link Hub

A streamlined, developer-focused link directory built for the **D4 Community**. This project serves as the central jumping-off point for all community platforms, designed with a focus on speed, typography, and interactive feedback.

## 🔗 Integrated Platforms

The hub provides direct access to the following community touchpoints:

| Platform | Purpose |
| :--- | :--- |
| **WhatsApp Group** | Real-time developer discussions and community chat. |
| **WhatsApp Channel** | Official announcements and broadcast updates. |
| **LinkedIn** | Professional networking and corporate updates. |
| **GitHub** | Open-source repositories and project collaboration. |
| **Discord** | Deep-dive technical channels and voice hangouts. |
| **Twitter / X** | Tech news, threads, and ecosystem engagement. |
| **YouTube** | Video tutorials, event recordings, and workshops. |
| **Volunteer Portal** | Application gateway for community contributors. |

## 🛠 Tech Stack (Link Features)

- **Next.js & React**: Powering the core link routing and structure.
- **Framer Motion**: Handling the entrance animations and hover-state transitions for each link card.
- **Lucide React**: Providing consistent, lightweight iconography for brand recognition.
- **Tailwind CSS**: Implementing a Geist-inspired design system with high-contrast dark mode support.

## ⚡ Interactive Features

- **Inertial Scrolling**: A custom hook-based smooth scroll experience for navigating the link list.
- **Spark Bursts**: Real-time visual feedback (spark particles) upon clicking any link or section of the UI.
- **Brand Theming**: Each link card dynamically inherits its brand color (e.g., Discord Blue, WhatsApp Green) during hover interactions.
